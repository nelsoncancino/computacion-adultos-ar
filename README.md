# Computación para Adultos — Realidad Aumentada

Prototipo de exposición realizado con **A-Frame + AR.js**. No requiere instalar una aplicación: se abre desde el navegador del celular, solicita acceso a la cámara y reconoce el marcador HIRO.

## Publicar con GitHub Pages

1. Entrá en **Settings** del repositorio.
2. En el menú izquierdo elegí **Pages**.
3. En **Build and deployment**, elegí **Deploy from a branch**.
4. Seleccioná la rama **main** y la carpeta **/(root)**.
5. Presioná **Save**.

La dirección esperada será:

- Experiencia AR: https://nelsoncancino.github.io/computacion-adultos-ar/
- Marcador para imprimir: https://nelsoncancino.github.io/computacion-adultos-ar/marker.html

## Cómo probar

1. Abrí la experiencia AR desde un celular.
2. Permití el acceso a la cámara.
3. Abrí o imprimí `marker.html` en otra pantalla/hoja.
4. Apuntá la cámara al marcador HIRO completo.
5. Debería aparecer una notebook 3D con WORD, EXCEL, WEB e IA.

## Recomendación para la exposición

Imprimir el marcador en A4, apoyarlo sobre una mesa bien iluminada y mantener todo el cuadrado dentro de la cámara. La primera versión usa solamente objetos nativos de A-Frame para evitar dependencias de modelos 3D externos.
